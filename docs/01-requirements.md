# 모델 요구사항 (Requirements)

## 1. 기능 요구사항 (Functional Requirements)

- 한국어 사내 문서(공지사항, 회의록, 진행 보고서)를 입력받아 요약할 수 있어야 함
- 문서 내 날짜, 담당자, 결정사항, 액션 아이템 등 핵심 정보를 놓치지 않고 추출해야 함
- 문서에 없는 내용은 지어내지 않고(환각 없음), 정보가 부족하면 "문서에 없음"으로 명시해야 함
- 표, bullet point 등 사용자가 요청한 출력 형식을 따를 수 있어야 함

## 2. 비기능 요구사항 (Non-Functional Requirements)

- **응답 속도**: 로컬 모델 기준 질문당 10초 이내
- **정확도**: 문서 내 핵심 정보 누락 없이, 환각(hallucination) 없이 요약
- **비용**: 로컬 모델은 무료(전력/하드웨어 비용만 발생), Cloud API는 소규모 비교 시 비용 상한 설정
- **리소스 제약**: 일반 노트북 환경(GPU 없이 또는 저사양 GPU)에서 구동 가능해야 함

## 3. 운영 요구사항 (Operational Requirements)

- 모델 버전을 고정하여 실험 재현 가능해야 함 (예: gemma3:4b, qwen3:4b 등 태그 명시)
- 모든 실험은 동일한 조건(temperature, 질문 세트, 실행 환경)에서 수행
- 사내 문서라는 데이터 민감도를 고려해, 외부로 전송되지 않는 로컬 실행을 우선 선호

## 4. 평가 기준 (Evaluation Criteria)

| 항목 | 가중치 | 측정 방법 |
|---|---|---|
| 정확성 / 환각 없음 | 최우선 | 문서에 없는 사실을 지어내는지 확인 |
| 형식 준수 (Instruction Following) | 2순위 | 표/bullet 등 요청 형식을 따르는지 확인 |
| 응답 속도 | 3순위 | 질문당 평균 응답 시간(초) |
