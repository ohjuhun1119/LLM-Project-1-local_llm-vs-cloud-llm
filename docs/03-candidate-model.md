## 후보 모델 선정 이유
- **Gemma 3 4B / Qwen 3 4B를 선택한 이유**

| 기준 | Gemma 3 4B | Qwen 3 4B-Instruct-2507-q4_K_M |
|---|---|---|
| Language | 140+ 언어 지원으로 한국어 포함 다국어 커버리지가 넓음 | Qwen 계열은 다국어 지원과 함께 한국어도 준수하게 처리 |
| Model Size | 4B, Q4 기준 약 3.3GB - 노트북 CPU로도 실용적 속도 | 4B, Q4_K_M 기준 약 2.5GB - 더 가벼움 |
| License | Gemma 라이선스로 상업적 사용 가능 | Apache 2.0 - 사용량 제한, 로열티 없이 자유로운 상업적 사용 가능 |
| Context Length | 131,072 토큰으로 긴 회의록, 보고서도 처리 가능 | 32,768 토큰으로 일반 공지, 회의록 요약엔 충분함 |
| Task | Chat, QA + 이미지 입력(멀티 모달) | Chat, QA + thinking 모드(단계별 추론)없이 즉시 답변하도록 분리된 instruct 전용 버전이라 응답 속도에 유리 |

- **Gemma 3 4B와 Qwen 3 4B-instruct-2507을 선택한 이유**

Gemma : thinking과 instruct 모델이 분리되어 나온 버전 중 즉답형 쪽이라, 사고 과정 없이 바로 답변 가능함

Qwen : 단계별로 따져본 다음 답을 내놓아 복잡한 지시사항을 놓치지 않고 처리할 수 있음

- **다른 모델들과의 비교**

Liama 4 Scout : 1000만 토큰을 읽을 수 있는 장점이 있지만 55GB 용량이 필요해 적절하지 않음

Phi-4 : MIT 라이선스(거의 아무 제약 없이 사용 가능)로 조건은 좋지만, 영어 중심 벤처마크에 최적화 되어 있어 한국어 사내 문서 요약에 취약할 수 있음

Liama 계열 : 오픈소스로 보이지만 라이선스에 다시 확인해야 할 조건이 걸려있는 모델 계열이라 상업적 사내 서비스에 쓰기 전 약관을 살펴봐야 함
